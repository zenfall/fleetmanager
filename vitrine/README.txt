GOOD ENTREPRENEUR SAS : SITE INTERNET (PROPOSITION 2)
=====================================

Fichiers
  index.html, qui-sommes-nous.html, activites.html, flotte.html,
  partenaires.html, contact.html   -> les 6 pages
  css/style.css                    -> tout le design
  js/config.js                     -> LES INFOS À COMPLÉTER
  js/main.js                       -> fonctionnement (menu, formulaires, flotte)
  fonts/                           -> police Bricolage Grotesque (licence libre OFL)
  img/                             -> déposez ici les photos (+ favicon)

À compléter avant la mise en ligne : js/config.js
  - adresse, téléphones, e-mail, horaires
  - numéro WhatsApp (format 221771234567)
  - lien d'intégration Google Maps
  - chemins des photos (ex. "img/entrepot.jpg")
  - les 5 véhicules (nom, type, places, bagages, photo)

Formulaires
  Aucun serveur nécessaire : les messages s'ouvrent dans WhatsApp
  ou dans la messagerie e-mail du visiteur, déjà rédigés.

Mise en ligne
  Copier tout le dossier tel quel chez n'importe quel hébergeur
  (hébergement mutualisé, Netlify, GitHub Pages, etc.).

Logo
  img/logo.png          -> logo complet, fond transparent
  img/logo-symbole.png  -> symbole seul (en-tête et pied de page)
  img/favicon*.png      -> icônes d'onglet et d'écran d'accueil
  Ils ont été détourés à partir d'une image JPEG en 640 px. Si le client
  possède le logo en SVG, PNG haute définition ou PDF, remplacez ces
  fichiers par ces versions (mêmes noms) pour un rendu plus net.
